# รายการไฟล์ภาพที่ต้องทำ — Battle Arena (VAreCrazy Card Battle)

สำหรับให้เจ้าของโปรเจกต์ (Toon) ออกแบบภาพต่อผ่านแชท แล้วอัปโหลดมาที่โฟลเดอร์ `design-assets/arena/` ใน GitHub
ผู้เรียกใช้ในเกม: Claude จะประกอบภาพเหล่านี้เข้า prototype/หน้าเกมให้ (ตัวอักษร ตัวเลข การ์ด ปุ่ม เป็น HTML จริง ไม่ฝังในภาพ)

อ้างอิงภาพหลัก: Battle Arena ภาพแรกที่ Toon ส่งมา (โทนม่วง-ดำ-ทอง ดาร์กแฟนตาซี) · Prototype: `prototype/battle-arena-v2/`

## กติกาใหญ่ที่ใช้กับทุกไฟล์
1. **ห้ามมีตัวอักษร ตัวเลข โลโก้ปลอม หรือป้ายชื่อฝังในภาพ** (ยกเว้นไฟล์โลโก้) — ภาพ Reference เดิมมีป้าย "AJDD" พิมพ์ผิด จึงให้ใส่ชื่อเป็นข้อความ HTML แทน
2. **ห้ามมีการ์ด ช่องวางการ์ด หรือ UI ฝังในภาพพื้นหลัง** (ภาพ "สะอาด" ที่ซ้อนเลเยอร์ได้)
3. **ทิศแสงเดียวกันทุกไฟล์:** แสงหลักจากด้านบน/หน้า โทนม่วงเข้ม + ไฮไลต์ทอง + เรืองแสงม่วง/ฟ้าเล็กน้อย
4. **สีหลัก:** ม่วงเข้ม `#1a0a2e`–`#2b1248` · ม่วงเรือง `#a05cff` · ทอง `#d8aa3f`/`#ffe9a0` · ดำ `#0b0414`
5. **ไฟล์โปร่งใสให้ใช้ PNG หรือ WebP แบบมี alpha** · พื้นหลังเต็มภาพใช้ JPG/WebP คุณภาพสูง
6. **ขนาดทำที่ 2 เท่า** ของแคนวาสเกม (Desktop 1672×941 → ทำที่ 3344×1882) เพื่อความคมบนจอ Retina
7. **ตั้งชื่อไฟล์ตามรหัสในตาราง** (เช่น `S01-room-backdrop.jpg`) เพื่ออ้างอิงตอนคุยกัน
8. ตัวละครผู้ชม (Toon, Add, Nu, Ball) ต้องหน้าตาตรงกับ Reference เดิม — ถ้าใช้เครื่องมือสร้างภาพ ให้ส่ง Reference เป็นต้นแบบทุกครั้ง

## ลำดับความสำคัญ
- **P0 = จำเป็นต้องมี** เพื่อให้ได้ภาพใกล้ Reference (รวม 12 ไฟล์)
- **P1 = ควรมี** เพื่อความสวย/ความสม่ำเสมอ (รวมประมาณ 40 ไฟล์ ส่วนใหญ่เป็นไอคอนชุดเดียวกัน)
- **P2 = เสริมภายหลัง** (เอฟเฟกต์ ท่าผู้ชม)

| A03 | กรอบอวาตาร์เวอร์ชันฝั่งศัตรู (ไม่บังคับ) | 512×512 | โทนแดง/ม่วงต่างจากฝั่งเรา เพื่อแยกฝั่งให้ชัด | P2 |

กติกา Dynamic Avatar (ฝั่งโค้ด ตกลงแล้ว):
1. แสดง **เฉพาะรูป** ไม่แสดงอีเมล รหัสผู้เล่น คีย์ หรือข้อมูลเกมที่ไม่ควรเห็น
2. รับ URL แบบ `https://` เท่านั้น (ภายหลังควรจำกัดโดเมนที่อนุญาต/ผ่านที่เก็บไฟล์ของเรา เพื่อกันการนำ URL ที่ติดตามที่อยู่ผู้เล่นมาใช้)
3. ไม่มีรูป · URL ไม่ถูกต้อง · โหลดไม่ได้ → Default Avatar อัตโนมัติ
4. คงสัดส่วนภาพ (ครอปกึ่งกลาง ไม่ยืด)
5. **ปัจจุบันระบบโปรไฟล์ยังไม่มีฟิลด์รูป** (มีเฉพาะชื่อผู้เล่น) การเชื่อมรูปจริงต้องรอระบบบัญชี/Universe หรือได้รับอนุญาตให้เพิ่มฟิลด์ ก่อนหน้านั้นทุกคนใช้ Default Avatar
