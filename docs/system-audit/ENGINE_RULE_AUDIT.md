# Engine Rule Audit

> **AUDIT ONLY.** Behaviour below was read from source (`src/engine/game.ts` unless stated) **and** run through the real engine (`scripts/card-balance-verify.ts`, raw output in `docs/card-balance/engine-probe-output.json`). Documentation was not used as evidence. Tests: 28 files in `tests/` (grep finds 359 `it/describe` blocks); the last complete `npm test` run earlier in this work was 303/304 with the single failure fixed afterwards; **a full run was not repeated for this audit (UNVERIFIED that the suite is fully green now)**.

## 1. Rule table (verified)

| Area | Actual behaviour | Evidence |
|---|---|---|
| **LP** | Both players start at `RULES.lp = 100` (hard-coded constant). LP drops only by a **direct attack** (full effective ATK, DEF ignored) or nothing else: effects/spells/traps hit units only. LP 0 = loss. | `game.ts` line 12, 65-67, 122-124, attack case 347-362 |
| **LP per room** | **Not adjustable.** The room owner can set only name, public/private and **turn time (30-300 s)**. No `lp` option exists in `Rooms.create`, `/api/play/rooms`, the lobby UI or any local/remote branch (grep of all branches). The DB `game_rules.starting_lp = 8000` (status proposed) and `combat.ts DEFAULT_RULES.startingLp = 8000` are unused by the game. | `rooms.ts` 55-72 (`create` opts), `api.ts` rooms POST, `turn-timer.ts TURN_RANGE`; see finding E-1 |
| **Setup** | 40-card main deck shuffled with the seeded RNG, 5-card start hand, hand max 5. Drawing with a full hand does nothing (the card stays in the deck). | `createGame`; `draw()` line 72-79 |
| **Turn system** | `startTurn`: reset summon/evolve flags and `attacked`, poison tick (5 dmg, 3 turns), TRP-007, `turn_start` effects, draw 1 (deck empty = loss). Phases: main -> battle -> end via `next`. `endTurn`: TRP-006, `turn_end` effects, temporary ATK removed, active player switches. | lines 205-222 |
| **Summon** | Only Lv15 characters from hand, 1 per turn, free, into an empty slot of 7. A summoned unit cannot attack that turn. Lv40+ cannot be summoned ("เรียกได้เฉพาะตัวละคร Lv.15"). | case `summon` line 280-288 |
| **Attack** | Battle phase only; not on turn 1; each unit once per turn; not on the turn it arrived; locked units (TRP-004) cannot. Target a unit; the player can be attacked only when the enemy has **no units** at all. Defender counter-attacks (same formula) if both survive. | case `attack` 347-368 |
| **Damage / DEF** | `hit = max(1, floor(max(1, effATK - effDEF) x elementMultiplier))`, `effATK = max(0, atk + bonusAtk + auraAtk)`, `effDEF = max(0, def + bonusDef)`. DEF >= ATK still deals 1. Probe: ATK 30 vs DEF 0/10/29/30/99 = 30/20/1/1/1. | lines 58-60 |
| **Elements** | x1.5 if attacker element is "strong" vs defender, x0.75 if the defender is strong vs attacker, else 1. Matrix from `db/seed/elements.json` (bundled), **not** from the DB. Fire>nature,alchemy; water>fire; lightning>water; earth>lightning; nature>earth; poison>nature; alchemy>poison; dark<->holy; wind>poison; physical/neutral none. | `combat.ts` 10-17 |
| **Evolution** | 1 Evolution card (any, from hand) per step + sacrifice of N other **face-up units on the field**: to Lv40 = 1, Lv70 = 2, Lv99 = 3 (`RULES.sacrifice` keyed by TARGET level). Form chosen from the separate evolution deck (<= 15) or, without one, from hand. 1 evolution per turn. Same chain, next level. Fused units cannot evolve. New unit keeps **damage taken** (`evolveHp = max(1, newMax - (oldMax - oldHp))`) and spell bonuses (`bonusAtk` minus temporary part, `bonusDef`); poison and lock are reset; the new unit counts as just-arrived (cannot attack this turn). Old form and EVO card go to the graveyard. | case `evolve` 289-304; probe |
| **Evolution + trap** | TRP-005 cancels it: EVO card to graveyard, unit stays, no sacrifice, form returned. | line 296-298 |
| **Fusion** | FUS card + two characters from hand that are a fusion pair (from runtime data, either order): result = top card at 100 % + bottom card at 50 % per stat + pair bonus (max over matching rows); top card art/effects only; counts as the turn's summon; fused unit cannot evolve; on bounce (TRP-009) both cards return. Probe: BACKJI-015 + NONG-TAENGMO-015 = 136/49/0. DEF of both cards (currently 0) adds the same way. | `fusionBonus` 105-110, case `fuse` 305-318 |
| **Spells** | Main phase, by card ID (SPL-001..010), cast = hand to graveyard. **No per-turn spell limit** (probe: 3 casts in a turn). Numbers are hard-coded. | case `cast` 324-346 |
| **Traps** | Set face-down in 1 of 5 back slots; active from the **next** turn (`setTurn < turn`); event map `TRAP` (line 77): attack, direct attack, summon/fuse, evolve, turn_end, turn_start, destroyed, to_graveyard; one trap fires per event; interactive rooms ask the owner (`pending` replay, `respond`/`pass`); fired trap goes to the graveyard. | lines 77-97 |
| **Combo** | **Not implemented.** `has_combo` is metadata; the `combo` trigger is not parsed. | `effects.ts` parseRaw |
| **Effects** | Only wordings accepted by `parseEffect` run (see EFFECT_COMPATIBILITY_MATRIX). Limits are tracked per **unit instance** (`used[]`), so a re-summoned/re-evolved unit resets once-per-game effects. | `runEffects` 155-188 |
| **Graveyard** | Dead, sacrificed, evolved-away and fired cards go to the owner's graveyard; every other own unit's `to_graveyard` effect (LEON, OUFILLING) and TRP-010 react to it. SPL-006 returns a Lv15 character (hand must not be full). Graveyard is visible to both players. | `toGrave` 98-102 |
| **Win conditions** | LP 0; drawing from an empty deck at turn start; 3 turn timeouts (default turn 90 s, room-settable 30-300 s); opponent absent > 2 min; resign/leave. | `draw`, `dealLp`, `turn-timer.ts` TIMING/forfeit |
| **Server authority** | The server owns the state; clients send validated actions (`validateAction`, integer bounds) and get a redacted view (hand/deck/face-down traps hidden, seed zeroed, `stats` removed). Bot games run the same engine in the browser and pay **no** rewards (`Economy.award` is called only from `rooms.ts settle`). | `deck-view.ts viewFor`, `rooms.ts` 204 |

## 2. Findings

| ID | Sev | Finding | Evidence | Problem | Proposed solution |
|---|---|---|---|---|---|
| E-1 | **P2 / UNVERIFIED claim** | **"Room owner can adjust LP" is not in the source.** Owner statement: LP is 100 and the room owner can adjust it. Source: LP is the constant 100; only turn time, name and visibility are room options. If a branch/deploy outside this repo has it, it is **UNVERIFIED**. | `game.ts:12,67`; `rooms.ts:55-72`; all-branch grep | Any design/balance work that assumes an adjustable LP cannot be tested; rewards would be farmable at tiny LP. | If wanted: new engine work `opts.lp` (default 100, range e.g. 50-300), stored in the room row/meta, shown in the lobby; **no rewards when LP != 100** (or scale them); tests for 1 HP-point edge cases. Separate approval. |
| E-2 | P3 | Three LP numbers exist: engine 100, DB rule 8000 ("proposed"), legacy `combat.ts` 8000 (+ formula `max(0, ATK-DEF)` min 0 vs live `max(1, ...)`). | `combat.ts` 7,18; `game.ts` 12 | Confusing for anyone reading the Admin rules or `combat.ts`. | Mark/retire the legacy file and DB rule; set DB `starting_lp` to 100 (data change, separate approval). |
| E-3 | P2 | **SPL-007 steals a unit that can attack at once** (swapped unit keeps its old `summonedTurn`/`attacked`). | probe `spl007.stolenCanAttackSameTurn = true` | Strongest card in the game; trades a Lv15 for the enemy's best unit with immediate attack, and can empty the enemy board for a direct hit on LP 100. | ENGINE-PROP-01 (set `summonedTurn = turn` on both swapped units). |
| E-4 | P2 | **SPL-003 / SPL-004 stack without limit** (3 casts = DEF +45 or ATK +45); permanent until the unit leaves. Card text and effect row disagree (D-4). | probe; `game.ts` 330-331 | DEF 45 = unit takes 1 damage from almost anything; ATK +45 = one-turn kills. | ENGINE-PROP-02; fix text. |
| E-5 | P3 | No spell-per-turn limit; SPL-005 draw 2 repeatable. | probe `spellVolume` | Draw/tempo spam limited only by hand size. | ENGINE-PROP-03 (optional). |
| E-6 | P3 | `once_per_game` is per unit instance: SPL-006 revive + re-summon, or TRP-009 bounce + re-summon, re-fires on_summon effects (probe: CHAEM-015 drew again). One summon per turn bounds the loop. | probe `recursion` | Card advantage loops are slow but real. | Keep; add loop tests. |
| E-7 | P3 | LALAPING-070 `on_evolve` full heal removes the "keeps damage taken" penalty (probe 20/160 -> 320/320). | probe `lalaping070` | Evolution as a full heal. | Design decision (keep). |
| E-8 | P2 | **Combo not implemented**; two cards carry the flag. | `effects.ts` | Admin lets the owner create `combo` rows that never run; publish gate blocks FOLLOW-YOU-040. | Decide: implement or remove (IMPLEMENTATION_PLAN). |
| E-9 | P3 | Direct attack needs an empty enemy board but ignores DEF and elements and deals full ATK; at LP 100 a Lv15 with ATK 35-40 needs 3 hits. TRP-003 halves it. Board control is the whole game. | `game.ts` 347-362 | DEF changes in the balance proposal do not help against direct damage. | Account for it in balance (CARD_BALANCE_REVIEW_V2). |
| E-10 | P3 | Evolution sacrifice map exists in 3 forms: engine `{40:1,70:2,99:3}` (target level), DB rule `{15:1,40:2,70:3}` (source level), card text "1/2/3". Same numbers, different keys, **only the engine map is read**. | `game.ts` 12; `card-rules.json` | Drift risk if someone edits the DB rule expecting an effect. | Document; show "not read by engine" in Admin. |
| E-11 | P3 | Two engines in use for decks: `buildDeck()` (bot/random) puts Lv40/70 forms in the **main** deck, which the room validator forbids. | `deck-view.ts` 5-17 vs 50-66 | Inconsistent rule for the bot path. | Align `buildDeck` or document it as legacy. |
| E-12 | P3 | Draft cards are loadable in rooms (`status <> 'archived'`). | `rooms.ts` `loadPool` | Unpublished cards are playable. | Decision pending (F-04). |
